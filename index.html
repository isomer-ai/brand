Logos

24 variants, each in SVG, PNG, PDF, and Illustrator, with RGB versions for web and CMYK-adjusted versions for print. The default is horizontal · color. None of the files has a filled background, so each preview shows the background that variant is meant for.

Guideline

The design guideline covers logo construction, clear space, the full palette with Pantone references, and example applications.

Clear space

Clear space is measured in A, the width of the mark. Leave at least ½A around the horizontal lockup and ⅓A around the mark on its own. Don't recolor, stretch, rotate, or rearrange the logo.

For agents

This site is also meant to be read by AI agents. Everything on this page comes from one manifest, and every file has a stable URL.

Read the manifest

curl -s https://isomer-ai.github.io/brand/brand.json \
  | jq '.logo_defaults, .colors'

See also llms.txt and the README.

URL pattern

https://isomer-ai.github.io/brand/logos/
  {web|print}/{svg|png|pdf|ai}/{variant}.{ext}

On a light background use isomer-logo-horiz-color-white-bg. On a dark background use isomer-logo-horiz-color-dark-bg. For a square slot use isomer-logomark-color-white-bg.
